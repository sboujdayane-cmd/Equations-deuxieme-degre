2. Synthèse de théorie

La méthode dépend de la forme de l'équation. Il est donc essentiel de commencer par observer et simplifier avant d'appliquer automatiquement une formule.
Forme standard
ax²+bx+c=0

Avant d'utiliser le discriminant, regroupe tous les termes dans un seul membre.

Il faut avoir a≠0 pour obtenir une véritable équation du second degré.

Produit nul
A·B=0 ⇔ A=0 ou B=0

Exemple :

(x−1)(x+5)=0

Donc x=1 ou x=−5.

Factorisation

Quelques formes utiles :

x²−a²=(x−a)(x+a)
x²+2ax+a²=(x+a)²

On peut également chercher deux nombres dont la somme et le produit conviennent.

Discriminant
Δ=b²−4ac
  • Δ>0 : deux racines réelles distinctes ;
  • Δ=0 : une racine réelle double ;
  • Δ<0 : aucune racine réelle.
Formules des racines

Si Δ>0 :

x₁=(-b−√Δ)/(2a)
x₂=(-b+√Δ)/(2a)

Si Δ=0 :

x₀=−b/(2a)
Somme et produit

Si les racines sont x₁ et x₂ :

x₁+x₂=−b/a
x₁x₂=c/a

Ces relations sont utiles pour étudier le signe des racines ou déterminer un paramètre.

Signe des racines

Le produit permet souvent de connaître si les racines ont même signe ou des signes opposés.

  • x₁x₂<0 : racines de signes opposés ;
  • x₁x₂>0 : racines de même signe, si elles existent ;
  • x₁x₂=0 : au moins une racine nulle.

La somme permet ensuite de préciser le signe lorsqu'elles sont de même signe.

Équations avec paramètre

Quand un coefficient dépend de m ou de c :

  1. identifier a, b et c ;
  2. calculer Δ en fonction du paramètre ;
  3. étudier son signe ;
  4. traiter aussi les valeurs qui peuvent faire disparaître le terme x².
Équations rationnelles

Avant tout calcul, exclure les valeurs qui annulent un dénominateur.

Dénominateur ≠ 0

Ensuite, multiplier par un dénominateur commun puis résoudre l'équation obtenue.

Équations irrationnelles

Pour une équation contenant une racine carrée :

  1. déterminer les conditions d'existence ;
  2. isoler la racine ;
  3. élever au carré ;
  4. résoudre l'équation obtenue ;
  5. vérifier chaque solution dans l'équation initiale.
Substitution

Lorsqu'une même expression apparaît plusieurs fois, on peut poser une nouvelle inconnue.

t = expression répétée

Il faut ensuite revenir à x à la fin.

Systèmes

Certaines questions associent deux inconnues x et y. On peut utiliser substitution, addition ou les relations somme-produit.

x+y=S et xy=P

Alors x et y peuvent être vus comme les racines de :

t²−St+P=0

4. Raisonner sur les racines et les paramètres

C.2.8 Raisonnement

Nombre et signe des racines

On considère l'équation :

x²−7x+10=0

Sans calculer explicitement les racines, détermine :

  1. le nombre de racines réelles ;
  2. le signe de leur produit ;
  3. le signe de leur somme ;
  4. le signe de chacune des racines.
C.2.9 Paramètre

Discussion d'une équation

On considère :

x²+mx+m=0

Discute le nombre de solutions réelles selon les valeurs du paramètre m.
